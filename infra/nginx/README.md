# nginx — homelab landing page

Self-contained nginx stack serving the homelab landing page and the DevOps
wiki. No runtime dependencies — plain HTML/CSS/JS. Mirrors `~/Source/nginx`
on `node-one`.

## Structure

```
infra/nginx/
├── docker-compose.yml  # the stack (mounts ./html and ./conf.d)
├── conf.d/
│   └── default.conf    # server block: listen 80, root /usr/share/nginx/html
└── html/               # document root
    ├── index.html      # landing page (services + architecture)
    ├── favicon.svg
    ├── wiki/           # GENERATED from docs/wiki/ - do not edit by hand
    │   ├── index.html
    │   ├── log.html
    │   └── <page>.html
    └── assets/
        ├── css/style.css   # all styles (light + dark theme)
        ├── js/main.js      # theme toggle + footer year
        └── img/logo.svg
```

The wiki HTML is generated by `tools/build_wiki.py` (stdlib-only Python) from
the Markdown in `docs/wiki/`, and the output is committed. See
[Wiki](#wiki) below.

## Editing

- **Service cards:** in `html/index.html`, copy/edit an `<a class="card">`
  block. Change the `href`, name, description, and the status dot
  (`dot-on` = online, `dot-off` = planned/offline).
- **Architecture:** the `#architecture` section shows the `node-one` host
  (`ul.facts`) and the traffic-flow diagram (`ol.arch-flow`). Update the facts
  when the hardware changes and add `.arch-step` items as the topology grows.
- **Colors / spacing:** tweak the CSS variables at the top of
  `html/assets/css/style.css`. Both light and dark themes are defined there.

## Wiki

The DevOps wiki lives in `docs/wiki/` as Markdown (`index.md`, `pages/*.md`,
`log.md`). To publish it into the site:

```bash
make wiki          # or: python3 tools/build_wiki.py
```

This converts the Markdown to HTML under `html/wiki/`, rewrites `.md` links,
resolves `[[wikilinks]]`, and copies per-page frontmatter (date, tags). Commit
the generated files so `git pull` on `node-one` is enough to publish.

**Never edit `html/wiki/*.html` directly** — it is overwritten on the next
build. Edit the Markdown in `docs/wiki/` instead.

## Run it

```bash
cd infra/nginx
docker compose up -d
```

`docker-compose.yml`:

```yaml
services:
  nginx:
    image: nginx:stable
    container_name: nginx
    restart: unless-stopped
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./html:/usr/share/nginx/html:ro
      - ./conf.d:/etc/nginx/conf.d:ro
```

Because it is a bind mount, edit `html/index.html` and refresh — no container
restart needed. After `git pull` on the server, changes are live too.

## Preview without Docker

```bash
cd infra/nginx/html
python3 -m http.server 8080
# open http://localhost:8080
```
