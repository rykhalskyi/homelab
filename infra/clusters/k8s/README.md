# k8s cluster — Flux GitOps (node `node-one`)

Everything here is reconciled by Flux from `main`. There is no imperative
`kubectl apply` workflow; commit to `main` and Flux applies it.

## Layout

```
infra/clusters/k8s/           # cluster id: k8s (single node `node-one`)
├── kustomization.yaml        # entrypoint, reconciled by the `flux-system` Kustomization
├── flux-system/              # bootstrap (generated by `flux bootstrap`)
├── apps.yaml                 # -> ./apps          (dependsOn: infrastructure)
├── infrastructure.yaml       # -> ./infrastructure (wait: true)
├── infrastructure/           # cluster add-ons: Traefik, StorageClass, chart sources
└── apps/                     # workloads in the `homelab` namespace
```

## Verify / reconcile

```bash
flux get kustomizations
kubectl -n homelab get deploy,sts,po
flux reconcile kustomization apps --with-source
```

## Required out-of-band Secrets

All of these live in namespace `homelab` and are **never** committed (see
`.gitignore`). They must exist before the manifests that reference them roll
out. Creation commands and full context are in the wiki pages listed below.

| Secret | Keys | Used by | Documented in |
| --- | --- | --- | --- |
| `nextcloud-admin` | `nextcloud-username`, `nextcloud-password` | nextcloud | `nextcloud-on-k3s.md` |
| `nextcloud-db` | `username`, `password`, `postgres-password` | nextcloud, postgresql, `provision-db.sh` | `nextcloud-on-k3s.md`, `postgresql-pgadmin.md` |
| `nextcloud-redis` | `redis-password` | nextcloud (redis) | `nextcloud-on-k3s.md` |
| `byebyemoneylist` | `SILICONFLOW_API_KEY` | nextcloud (byebyemoneylist app) | `nextcloud-on-k3s.md` |
| `cloudflared-tunnel` | `TUNNEL_ID` | cloudflared | `k3s-gitops-nginx-cloudflared.md` |
| `cloudflared-credentials` | `credentials.json` (file) | cloudflared | `k3s-gitops-nginx-cloudflared.md` |
| `eurooffice-jwt` | `JWT_SECRET` | eurooffice | `eurooffice.md` |
| `pgadmin-auth` | `PGADMIN_DEFAULT_EMAIL`, `PGADMIN_DEFAULT_PASSWORD` | pgadmin | `postgresql-pgadmin.md` |
| `pullini-secrets` | `DJANGO_SECRET_KEY`, `DATABASE_URL`, `DJANGO_SUPERUSER_*` | pullini | `pullini-on-k3s.md` |

After creating `pullini-secrets`, provision its database role with:

```bash
bash infra/clusters/k8s/apps/pullini/provision-db.sh
```

## Conventions

- Pin every image by digest (`tag@sha256:...`) and every Helm chart to an exact
  version. The `update-*-pin.yml` workflows bump the app image pins.
- Keep manifests free of secrets; use `existingSecret` references and document
  required Secrets above.
- Public hosts are `*.otakeessen.com` (Cloudflare tunnel -> Traefik). TLS
  terminates at Cloudflare; Traefik entrypoints are plain HTTP.
