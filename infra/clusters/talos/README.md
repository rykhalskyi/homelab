# talos — the Talos cluster

Three-node Talos/Kubernetes cluster (planned). Only **`node-two`**
(`192.168.2.234`) is up today; `node-one` and `node-three` will join later.

This directory holds two separate layers — keep them distinct:

## Flux layer — cluster-wide (one set, shared by all nodes)

Reconciled by Flux from `main` (entrypoint: `flux-system/gotk-sync.yaml`).

```
infra/clusters/talos/
├── kustomization.yaml      # Flux entrypoint (must list flux-system, else Flux prunes itself)
├── flux-system/            # controllers + GitRepository/Kustomization (generated by flux bootstrap)
├── apps.yaml               # Kustomization CR -> ./apps          (to add)
├── infrastructure.yaml     # Kustomization CR -> ./infrastructure (to add)
├── apps/                   # workloads          (to add)
└── infrastructure/         # cluster add-ons    (to add)
```

## Talos machine layer — NOT reconciled by Flux

**Cluster-wide** files live at this root and are **local-only** (gitignored) —
they are identical for every node:

| File | Purpose |
|------|---------|
| `secrets.yaml` | Talos cluster CA + keys (same on all nodes) |
| `talosconfig` | admin client config (cluster endpoint) |
| `talos.kubeconfig` | admin kubeconfig (for `kubectl`/k9s) |

**Per-node** machine configs live under `nodes/<node>/` (also local-only; they
embed the cluster secrets plus node-specific network/hostname):

```
nodes/
└── node-two/
    ├── controlplane.yaml   # static IP 192.168.2.234, hostname node-two, install disk
    └── worker.yaml
```

Generate a node's config (from this directory):

```bash
talosctl gen config talos https://192.168.2.234:6443 \
  --with-secrets secrets.yaml \
  --install-disk /dev/nvme0n1 \
  --config-patch @nodes/<node>/patch.yaml \
  --with-docs=false --with-examples=false \
  -t controlplane -o nodes/<node>/controlplane.yaml
```

Apply it from maintenance mode (the node's current DHCP IP):

```bash
talosctl apply-config --insecure -n <dhcp-ip> --file nodes/<node>/controlplane.yaml
```

> The running cluster's admin access is configured in `~/.talos/config`
> (context `talos`) and `~/.kube/config` (context `talos`) — see the wiki pages
> on Talos commands and kubectl contexts. Files here are the source/backup.
